# rebudget
Personal finance app focused on manual bookkeeping, budgeting, monthly review and long-term spending insights.

## Features

- Manual bookkeeping
- Multi-level categories
- Multi-tag support
- Budget planning
- Recurring bills
- Monthly review
- Special expense isolation

## Tech Stack

- Flutter
- Dart
